# Starter UTS Pemrograman Mobile: Profil Mahasiswa

## Menjalankan
1. Jika folder `android/` dan `web/` belum ada: `flutter create --platforms=web,android .`
2. `flutter pub get`
3. `flutter run -d chrome`
   Uji lebar layar 360 dp (ponsel) dan 800 dp (tablet/desktop) lewat DevTools Chrome.

## Struktur
- `lib/data/data_profil.dart`: data profil (ganti dengan data Anda).
- `lib/models/profil.dart`: model.
- `lib/screens/halaman_profil.dart`: halaman utama dan tata letak responsif.
- `lib/widgets/`: header, tombol ikuti, statistik, kartu info, keahlian, galeri proyek.
- `assets/foto_profil.jpg`: foto pengganti. Ganti dengan foto wajah Anda sendiri.

Petunjuk tugas lengkap ada di Dokumen Mahasiswa.
